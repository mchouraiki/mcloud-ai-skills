# Post 2: Safer Web Development

This mini-project provides a host-neutral web-development skill for HTML, CSS,
JavaScript, PHP, React and Tailwind projects.

## Contents

- `article.md`: website article source
- `SKILL.md`: main skill entry point
- `agents/`: optional host interface metadata
- `assets/`: skill icon
- `SOURCES.md`: source and attribution notes
- `LICENSE`: CC BY 4.0 license for the original MCloud material

## Use

Load `SKILL.md` using the host tool's skill-discovery rules. Start with
read-only inspection, identify the authoritative source and deployment path,
preserve existing routes and security controls, and ask for approval before
production or externally visible changes.
