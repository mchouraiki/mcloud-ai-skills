# MCloud AI Skills

Reusable Markdown skills for practical AI-assisted technical work.

This repository contains the three-part MCloud Solutions series:

1. [Post 1: Reusable AI Skills with SKILL.md](post-1-generic-skill-md/)
2. [Post 2: Safer Web Development](post-2-web-development/)
3. [Post 3: SEO Skills](post-3-seo-skill-pack/)

Each post is a separate mini-project with its own README, article source and
downloadable skill material. LinkedIn and Instagram drafts are kept outside
this public repository.

## Repository use

Open the README inside the relevant post directory first. Then load the
included `SKILL.md` or core guidance according to the AI tool's own discovery
rules. Host-specific commands and installation paths must not be assumed.
