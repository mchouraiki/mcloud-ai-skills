# Post 1: Reusable AI Skills with `SKILL.md`

This mini-project introduces reusable AI skills, shared core guidance and
validation boundaries.

## Contents

- `article.md`: website article source
- `core-guidance/`: reusable always-on guidance template
- `examples/generic-website-audit/SKILL.md`: generic example skill
- `examples/mcloud-safe-web-changes/SKILL.md`: practical safe-change example
- `SOURCES.md`: source and attribution notes
- `LICENSE`: CC BY 4.0 license for the original MCloud material

## Use

Start with `core-guidance/core-guidance.md`, replace its bracketed fields, and
load only the specialist skill relevant to the task. The files describe a
workflow. They do not train a model or create permanent memory.
