# SEO Skills Package

This package contains 25 Markdown skills adapted from
[AgriciDaniel/claude-seo](https://github.com/AgricIDaniel/claude-seo), source
version `v2.2.4`.

## Compatibility

The source project targets Claude Code. The skill folders are portable Markdown
guidance, but commands, subagents, MCP tools, API integrations and optional
extensions are host-specific. Treat those references as conditional and use
only tools available in the current session. Start audits read-only and never
claim a result without evidence.
