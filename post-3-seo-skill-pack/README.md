# Post 3: SEO Skill Pack

This mini-project contains 25 focused SEO workflows for technical SEO, audits,
content, schema, sitemaps, local SEO, GEO and related work.

## Contents

- `article.md`: website article source
- `skills/`: 25 individual SEO skill folders
- `skills/README.md`: compatibility and usage notes
- `skills/LICENSE`: original MIT license for the adapted skill files
- `THIRD_PARTY_NOTICES.md`: upstream attribution and modifications
- `SOURCES.md`: article and skill sources

## Use

Start with the skill that matches the request. The source project targets
Claude Code, so command examples, MCP tools, subagents and optional extensions
are host-specific references. Use only the tools available in the current
environment. SEO audits should normally begin read-only and every finding must
be supported by evidence.
